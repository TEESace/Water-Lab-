# Waterlab 3D · เมืองริมน้ำ

เว็บภาษาไทยจำลองเมืองสมมติที่มีภูมิประเทศ ถนน อาคาร สะพาน คลอง บึง และเขื่อน หน่วยทุกแกนในฉากคือเมตรและระดับทั้งหมดอ้างอิง 0.00 ม. เดียวกัน

## เปิดเว็บจากโค้ด

แตก ZIP แล้วเปิด Terminal ในโฟลเดอร์ `waterlab-3d` จากนั้นรัน:

```bash
python -m http.server 8080 --directory dist
```

บน macOS หรือ Linux ใช้ `python3` ได้ บน Windows ใช้ `py` ได้ แล้วเปิด `http://localhost:8080` ใน Chrome หรือ Edge ที่รองรับ WebGL

โฟลเดอร์ `dist/vendor` มี Three.js และ OrbitControls รวมไว้แล้ว ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ส่วนฟอนต์ออนไลน์มีฟอนต์สำรองของเครื่อง

ดับเบิลคลิก `index.html` อาจไม่ทำงาน เพราะเว็บใช้ JavaScript modules ควรเปิดผ่านเว็บเซิร์ฟเวอร์

## ไฟล์สำคัญ

- `dist/index.html` โครงหน้าและข้อความภาษาไทย
- `dist/style.css` รูปแบบหน้าเว็บและจอมือถือ
- `dist/app.js` ฉาก 3D เครื่องมือสร้างทางน้ำ และแผงปรับค่า
- `dist/city.js` ภูมิประเทศ ถนน อาคาร สะพาน และสภาพแวดล้อมของเมือง
- `dist/sim.js` แบบจำลองการไหล ระดับน้ำ ประตู และน้ำล้น
- `dist/vendor/` ไลบรารี 3D พร้อมไฟล์ลิขสิทธิ์

## ขอบเขตแบบจำลอง

เขื่อนกักน้ำด้วยบานประตูสองช่อง เปิดปิดได้เป็นเมตร และปล่อยน้ำผ่านสันเมื่อผิวน้ำสูงกว่าระดับสันเขื่อน แบบจำลองรักษาปริมาตรน้ำในแหล่งเก็บ น้ำล้นถูกนับแยกเป็นปริมาตรสะสม ฉากเมืองเป็นภูมิประเทศสมมติ ส่วนน้ำล้นยังไม่กระจายไปท่วมถนนหรืออาคาร การจัดวางยังอยู่ในหน้าเว็บและไม่บันทึกเมื่อโหลดหน้าใหม่
